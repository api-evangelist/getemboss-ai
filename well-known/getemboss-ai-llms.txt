# Emboss

Emboss is a PDF form-filling API for developers. Upload a flat PDF and Emboss detects the fields, builds a JSON contract, and returns a filled, fillable PDF. Authenticate every request with a Bearer API key.

## Pricing
Usage-based: pay per form, no subscription. Extraction and fill are billed separately, with a free tier. See https://getemboss.ai/pricing.

## Try it in the browser
Fill a PDF form without code (upload form + context docs, download the filled PDF): https://getemboss.ai/fill
Batch fill PDF forms from a spreadsheet (upload one form + a CSV/Excel, get one filled PDF per row as a ZIP): https://getemboss.ai/batch-fill

## API Endpoints
Base host: https://api.getemboss.ai
- POST /forms: Create a form (auth required)
- GET /forms/{id}: Get a form (auth required)
- GET /forms: List your forms (auth required)
- DELETE /forms/{id}: Delete a form (auth required)
- GET /forms/{id}/contract: Get the contract (auth required)
- POST /forms/{form_id}/with-context: Fill an existing form with context (auth required)
- POST /forms/with-context: Fill with context (auth required)
- GET /forms/with-context/{job_id}: Get the fill job (auth required)
- POST /forms/{form_id}/suggest-mapping: Suggest a column mapping (auth required)
- POST /forms/{form_id}/fill-batch: Start a batch fill (auth required)
- GET /forms/fill-batch/{batch_id}: Get batch status (auth required)
- GET /forms/fill-batch/{batch_id}/rows/{n}/pdf: Download a row PDF (auth required)
- GET /forms/fill-batch/{batch_id}/zip: Download all rows as ZIP (auth required)
- POST /sessions: Create a session (auth required)
- GET /sessions/{id}: Get session state (auth required)
- PUT /sessions/{id}/fields: Direct field fill (auth required)
- POST /sessions/{id}/fill: Render the filled PDF (auth required)
- GET /sessions/{id}/pdf: Download the PDF (auth required)
- GET /usage: Usage (auth required)
- POST /forms/quote: Quote (auth required)
- GET /health: Health (public)
- POST /forms/read: Read a filled form back (auth required)
- POST /proposals/{proposal_id}/attachments: Attach a document to a proposal (auth required)
- DELETE /proposals/{proposal_id}/attachments/{n}: Remove an attachment (auth required)
- GET /proposals/{proposal_id}: Read a proposal (auth required)
- POST /proposals/{proposal_id}/commit: Commit a proposal, optionally as a package (auth required)
- POST /fax: Send a fax (auth required)
- GET /fax/{job_id}: Get a fax receipt (auth required)
- GET /artifacts/{artifact_id}: Get an artifact (auth required)
- GET /artifacts/{artifact_id}/content: Get an artifact's content (auth required)
- POST /utilities/compose_pdf: Compose a PDF (auth required)
- POST /utilities/merge_pdf: Merge whole PDFs (auth required)
- POST /utilities/extract_pages: Extract pages (auth required)
- POST /utilities/delete_pages: Delete pages (auth required)
- POST /utilities/reorder_pages: Reorder pages (auth required)
- POST /utilities/rotate_pages: Rotate pages (auth required)
- POST /utilities/inspect_pdf: Inspect a PDF (auth required)
- GET /library: List or search the library (public)
- GET /.well-known/ard.json: The catalogue and how to verify an entry (public)
- GET /.well-known/did.json: The DID document (public)
- GET /.well-known/mcp.json: The MCP server record (public)
